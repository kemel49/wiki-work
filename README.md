# wiki-work
This repository contains the **MediaWiki templates and Scribunto Lua modules** that I have created for Wikimedia projects.

The files here represent my work on Wikipedia and are kept up to date with my latest edits to the respective templates and modules on-wiki.

## Contents
- **Template/**: Wikitext-based MediaWiki templates
- **Module/**: Scribunto Lua modules

## Status
Most of the templates and modules in this repository are already created and in use on Wikipedia.

Some files may be under development or testing before being added to Wikipedia.

## Development
New modules and changes may be developed and tested here before being deployed on Wikipedia.

Issues are used to track larger development work, while commits record the changes made to the code.

## Note
This repository is primarily an archive of my Wikimedia work. The live versions of these templates and modules are maintained on Wikimedia projects.
